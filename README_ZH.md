## 关于本作

这是第一次使用 Thunder Engine 制作 Mario Forever(MF)的试水之作。关卡名对应原版 Happy Mario World(HMW)模板,但难度并非循序渐进,可按自己的节奏探索每个世界。每个世界都保留 HMW 的关卡对应关系,同时补入细节调整、剧情过场、通关存档和更多探索提示。

## 关于本仓库

本仓库是 Happy Mario World Reforged 的官方**作品档案网站**。它是一个 Vite + React + TypeScript 单页应用,部署在 GitHub Pages 上;发布产物以 GitHub Releases 形式托管于此。

上方部署的站点在线呈现关卡档案、版本日志与下载页面,无需克隆即可浏览。

### 本地开发

需要 Node.js 与 [pnpm](https://pnpm.io)(锁定 `pnpm@11.0.8`)。

```bash
pnpm install
pnpm dev        # 启动开发服务器
pnpm build      # 类型检查 + 生产构建,输出到 dist/
pnpm preview    # 预览生产构建
```

推送到 `master` 分支会触发 `.github/workflows/deploy.yml` 中的 GitHub Actions 工作流,以 Pages 基址构建并将 `dist` 发布到 GitHub Pages。
